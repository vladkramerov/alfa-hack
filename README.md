## Локальный запуск

Python 3.12. Локальное подмножество разрешённых зависимостей: `python3 -m pip install -r requirements-experiments.txt`. На Mac для XGBoost/LightGBM нужен OpenMP (`brew install libomp`). Исходный requirements.txt для платформы не изменён.

```bash
python3 solution.py /полный/путь/к/task.md
```

CSV определяются по task.md; `submission.csv` и история создаются рядом с ним. Платформа запускает ровно `python3 solution.py task.md` в каталоге задачи и сама задаёт OPENAI_BASE_URL/API_KEY/MODEL. `.env` не входит в ZIP и Git. Агент читает переменные окружения; для платформы отдельный конфиг не нужен.

## Коллегам: начать с готовых результатов

Не переобучайте H70–H75 для просмотра метрик: таблицы, исходные сохранённые прогнозы, splits и параметры уже опубликованы в results/2026-10-24/. Большие fitted joblib и сырые исходные CSV в Git не включаются. Для пересчёта без обучения расположите исходные публичные файлы в data/regression/ и data/multiclass/ (включая task.md), затем:

```bash
python3 -m experiments.verify_sergey_metrics
```

Процесс следующей проверки: прочитать HYPOTHESES.md → зарегистрировать новый механизм/критерий/параметры до fit → сохранить отдельный results/.../HYP-... → дописать фактический исход → продвигать только после сопоставимых проверок. API/платформенные действия и неизвестные private метрики не считать проверенными автоматически.
