# Инструкции для работы в проекте

Перед работой прочитай [Codex.md](Codex.md) и следуй описанному процессу Spec-Driven Development.
Требования конкретной задачи и прямые инструкции пользователя имеют приоритет.
Отвечай на языке пользователя; по умолчанию — кратко, до трёх коротких предложений.
После каждой проверки гипотезы сохрани отдельный отчёт и артефакты в `results/` по правилам из `Codex.md`.
Перед КАЖДОЙ новой гипотезой прочитай [HYPOTHESES.md](HYPOTHESES.md): проверенные направления не повторять; новую гипотезу записать до запуска, результат — сразу после проверки. Один новый seed или имя не делают гипотезу новой.
