# Примечание к происхождению кода HYP-009/010

Хеши полных модулей в evidence.json собирались при завершении worker, отдельный стартовый snapshot новой серии не создавался. Между оценками в worker добавлялось сопоставление столбцов вероятностей при **full refit**, а в data — порядок вероятностей резервного ответа; эти ветви не вызываются при evaluate RMSE/Macro F1. Обучающий путь, параметры моделей, признаки, split и формулы метрик четырёх оценок не менялись. Поэтому hash целого файла на завершении не следует трактовать как гарантированный стартовый snapshot каждого процесса. Сохранённые validation-предсказания независимо сверены без повторного обучения; выводы ограничены данным протоколом.
