## Выбор подхода

1. Полная замена на внешний агент: отклонена до сопоставимого воспроизведения;
   источники имеют разные стенды, более слабые контроли и отрицательные исходы.
2. Автопоиск ключа/многозадачная metric-aware политика: полезно для неизвестных
   задач, но само по себе не доказывает улучшения публичного RMSE/F1.
3. Выбран узкий проверяемый перенос идеи multi-lag+native missing; полный
   ансамбль и новыйseed не объявляются новым механизмом сами по себе.

Ограничения: повторно просмотренный outer разведочный, API endpoint неизвестен,
ключи/чужие модели/внешние обучающие данные не используются.
