# SPEC015: ограниченная проверка TabM-mini

Статус: исследовательский spike завершён по прямому ответу пользователя «попробуй» на предложение TabM и ансамбля с действующей моделью. Детали реализации выбраны агентом; не утверждается отдельное согласование документа. [Итог и ограничения](../../results/2026-10-24/series-tabm-mini-v1/report.md): outer RMSE33.979840 против34.142888, Macro-F1.66027959 против.65930841; 4 новых learner fits, 0 старых refits. Поставка не изменена; интеграция полного runtime-графа отдельно не проверена.

REQ-001. Проверить новую архитектуру TabM-mini на регрессии и классификации. Новизна относительно H62 (FM) и H72/H94 (teacher-residual MLP): обучаемый random-sign входной адаптер каждого участника, общий двухслойный ReLU MLP, независимые выходные головы, средняя loss по участникам, усреднение их прогнозов/вероятностей. Не копировать чужие веса.
REQ-002. Torch отсутствует локально, pip не имеет сетевого доступа (WinError10013). Разрешённый spike использует самостоятельную NumPy-реализацию архитектуры reference TabM-mini без новых зависимостей; это не официальный пакет и не воспроизведение результатов статьи. Корректность backprop проверить центральными конечными разностями.
REQ-003. Fit-only preprocessing: numeric median + missing flags + quantile-normal (не более256quantiles), categorical OHE(handle_unknown=ignore, max_categories=64), без удаления строк; категории и статистики только из fit. Задачи/labels/колонки не зашиты в estimator. Regression original-y standardized MSE; classification unweighted CE. k8,width64,depth2,AdamW lr.003,wd.0001,batch256,60epochs,seed42; не более240сек/fit, 900сек на всю H108. Последняя полностью завершённая эпоха используется при timeout; отсутствие завершённого шага — техническая ошибка.
REQ-004. HYP-108 регистрируется до realfit. Старые learner fits не повторять. Контроли — cached H107 regression и H78 classification. Regression splits — H70 inner/outer; class splits — H78 inner/outer. SHA/splits/classes/y проверить, сохранить predictions, конфиг, состояние, время и аудит. Каждая задача/часть — отдельный results/ и немедленный исход в журнале. Полный HYPOTHESES.md читать до каждого fit.
REQ-005. На inner оценить pure и смеси с cached control: регрессия — analytical MSE-optimal weight в[0,1], классификация — фиксированная сетка weight[0,.1,.25,.5,.75,1] по Macro-F1. Нулевая доля нового метода не считается успехом. Outer только если выбранная смесь строго улучшает контроль; заморозить вес и конфигурацию до загрузки outer. Никакого выбора эпох по outer; checkpoint — только по training loss, epochs фиксированы. Оба cached outer уже видели ранее: результаты exploratory.
REQ-006. Spike не меняет solution.py, baseline, requirements и ZIP. При неуспехе сохранить пригодный исследовательский код и честный отрицательный результат, без внедрения в автоматический portfolio. Проверки — unittest discover всего проекта, независимый replay метрик/проверка leakage и повторов; состояние существующего WIP сохранить.

Варианты: официальный PyTorch пакет предпочтителен для дальнейшей полноценной репликации, но недоступен в текущем окружении; NumPy TabM-mini позволяет выполнить проверяемое обучение сейчас; замена на обычный sklearn MLP не проверяла бы заявленную новую архитектуру.

Источники: https://github.com/yandex-research/tabm/blob/main/tabm_reference.py (ScaleEnsemble, arch_type=tabm-mini, NLinear output), https://proceedings.iclr.cc/paper_files/paper/2025/file/c1ba41c694834aeef91ae161711d4939-Paper-Conference.pdf .
