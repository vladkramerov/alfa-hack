# Проверки и статус валидации

Обновлено: 2026-10-23. Это журнал того, что уже проверено, и ограничений, которые ещё мешают считать пакет окончательно готовым.

## Выполнено

- Текущие unit результаты: `results/unit-v2.xml` — **45 passed**.
- Предыдущая clean-room проверка: 9 сценариев прошли на ZIP версии v1. Она подтверждает тот конкретный архив, но не является проверкой окончательного текущего пересобранного ZIP.
- Unit/reliability набор проверяет ошибки LLM endpoint (пустой ответ, HTTP 500, invalid JSON, задержка/timeout), восстановление поиска, эквивалентные proposals, неизвестные DSL-колонки, формирование submission, короткий бюджет и завершение зависшего worker.
- Тесты API используют локальный mock HTTP server; реальный Qwen endpoint не настроен и не тестировался.
- `experiments/package_solution.py` проверяет синтаксис Python, фиксированный состав flat ZIP, целостность ZIP и неизменность официального `requirements.txt`; SHA каждого файла и архива сохраняются рядом в manifest.
- Исторические результаты и протоколы описаны отдельно в [HYPOTHESES.md](HYPOTHESES.md). Они не заменяют текущую nested-проверку и не являются платформенными score.

## Текущие public snapshots

`results/public-v1/` — сохранённый запуск старой версии, где внешний audit gate использовался для выбора кандидата. Его модели/оценки exploratory и не описывают поведение текущего engine.

`results/public-v2/` — запуск текущего изолированного source с выбором по search winner, парным baseline/winner audit только для диагностики и full refit именно search winner. Для сохранённого regression baseline run: search RMSE `44.97708820054441`, outer audit RMSE `57.86553092977038`; baseline и winner здесь совпадают. Эти числа относятся к известным публичным данным, ранее использовавшимся в исследовании, и не дают независимой оценки приватного теста или платформенного score. В summary указаны `audit_used_for_selection=false`, `audit_status=completed`, `final_refit.status=completed`, `llm_status=unconfigured`.

## Незавершённые финальные проверки и средовые ограничения

- Clean-room проверка 9 сценариев прошла на ZIP v1; ZIP после текущих правок нужно пересобрать и повторить clean-room сценарии. До этого итоговый пакет не считается проверенным.
- Доступный локальный runtime — macOS с Python 3.12 и subset ML-зависимостей, достаточным для проверенных моделей. Это не полная официальная среда `requirements.txt`.
- Linux Docker daemon недоступен, поэтому запуск внутри Linux-контейнера организатора не выполнен.
- Локальный OpenMP runtime из `/private/tmp/alfa-openmp/...` использовался только для разработки macOS. Он не включается в ZIP; пакет использует зависимости официального окружения.
- Реальные креденшалы/API Qwen отсутствуют. LLM поведение проверено mock-сервером; модельный endpoint платформы остаётся непроверенным.
- Значения hidden-test baseline не предоставлены. Локальные RMSE/F1 нельзя преобразовать в официальный score.

Перед заявлением «финально проверено» необходимы пересборка ZIP из текущего source, повтор clean-room минимум по 9 scenario, проверка итоговых SHA и, когда станет доступна среда, smoke test в совместимом Linux runtime.
