## Интерфейс предоставленного baseline

- Вызов: Python-скрипт получает путь к `task.md` первым позиционным аргументом, по умолчанию использует `task.md`.
- Переменные: `OPENAI_MODEL` читается явно; `AsyncOpenAI()` использует стандартную конфигурацию SDK, в описании запуска перечислены `OPENAI_API_KEY` и `OPENAI_BASE_URL`.
- MCP-сервер запускается тем же Python через `--mcp-server`; рабочая папка — каталог Markdown-задачи.
- Инструмент `run_python` создаёт новый процесс для каждого вызова; файлы сохраняются, переменные между вызовами не сохраняются.
- На вызов инструмента задан timeout 1800 секунд; stdout и stderr ограничиваются последними 12 000 символами каждый.
- Агент делает до 100 запросов к LLM; это настройка baseline, а не подтверждённое отдельное требование платформы.
- `run_python` получает сокращённое окружение: PATH и PYTHONIOENCODING, без автоматической передачи API-ключа исполняемому коду.
- В обоих `task.md` результат требуется записать как `submission.csv` рядом с Markdown-файлом задачи.

## Несоответствия и вопросы к окружению

1. В ZIP CSV лежат непосредственно рядом с `task.md`, однако условия ссылаются на `regression/participants/` и `multiclass/participants/` относительно него. Для локального запуска потребуется явное сопоставление путей; исходные условия не исправлялись.
2. Baseline импортирует `mcp`, но в предоставленном requirements нет такого пакета. Это не доказывает его отсутствие в Docker организаторов; состав контейнера нужно уточнить или проверить до упаковки.
3. PDF, с. 6, требует `solution.py` в корне ZIP; на с. 17 при описании таймера упоминается `script.py`. Основным требованием считаем явно описанный формат сдачи `solution.py`, расхождение сохраняем для сверки.
4. В PDF запрещён интернет из контейнера, но предусмотрен доступ к LLM API. Адрес разрешённого endpoint и его доступность ещё не проверены; секретные ключи в документацию не записываются.
5. Значения метрик платформенного бейзлайна для нормировки баллов отсутствуют. Из локальных RMSE и Macro F1 нельзя вычислить фактический leaderboard score.
