# HYP-007: L1 против L2 в линейных моделях

- Дата: 2026-10-23, Москва.
- Спецификация: [SPEC-002](../specs/SPEC-002-preprocessing-model-comparison.md).
- Статус: Проверена.

## Утверждение

После независимого inner-подбора силы штрафа один из L1/L2 вариантов покажет лучшую outer-метрику; победитель заранее не предполагается.

## Метод и критерий до запуска

Lasso(alpha .01,.1,1) vs Ridge(alpha .1,1,10); LogisticRegression saga penalty l1/l2 C .01,.1,1.
Две задачи и два семейства деревьев оцениваются раздельно; меньший RMSE / больший Macro F1 — выигрыш на неизменной validation.
Сначала inner train/validation; все конфигурации outer замораживаются до первой outer-оценки.
Для классификации дубликаты исходных признаков сгруппированы, для регрессии используется время.
Каждый запуск сохраняет точный split, параметры, hashes, предупреждения, preprocessing audit и validation predictions.
L1/L2 сравниваются только после отдельного подбора каждого штрафа; несходимость отмечается и ограничивает вывод.
Одиночный split и ограниченная сетка не подтверждают общее превосходство метода.
