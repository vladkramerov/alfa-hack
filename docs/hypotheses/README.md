# Гипотезы

Перед КАЖДОЙ проверкой обязательно прочитать [единый HYPOTHESES.md](../../HYPOTHESES.md); новая гипотеза записывается до запуска, исход сразу после. Повторы запрещены прямым поручением пользователя. HYP-001…010 и старая история уже проверены.
Для [SPEC-002](../specs/SPEC-002-preprocessing-model-comparison.md) до запуска сформулированы HYP-001…HYP-007: корреляции, VIF, scaling, Yeo–Johnson, feature engineering, CatBoost L2 и линейные L1/L2.
Отчёты отдельных запусков сохраняются в [results](../../results/README.md).
Создавай `HYP-NNN-<slug>.md` по [шаблону](_template.md).
Задавай критерий успеха до эксперимента и сохраняй ссылки на все запуски, включая отрицательные и прерванные.
Перед новой проверкой изучи [журнал результатов](../../results/README.md).
