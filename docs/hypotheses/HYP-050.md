## Утверждение и основание

Динамическое подавление лёгких примеров внутри loss может направить tree updates
на трудные классы и увеличить Macro-F1. Зафиксирован **невзвешенный** focal loss
`mean[-(1-p_y)^2*log(p_y)]`, без alpha и без CE-mixture; gamma2 соответствует
исходному предложению. Мотивация — [Lin et al.](https://arxiv.org/abs/1708.02002),
эффективность на данном табличном наборе остаётся гипотезой.

H39 задавала постоянные веса OOF-трудности; focal пересчитывает множитель на
каждом boosting шаге и дифференцирует его. H51 меняла class prior в softmax,
H72/H80 оптимизируют soft count-F1, H77 использует rank Lovasz. Эти методы
не повторяются. H50 ранее была только предложена, численного исхода не имела.
Инициализация совместимым supplied teacher — frozen residual protocol SPEC011;
новый teacher/SMOTE/ансамбль здесь не обучается.

## Frozen конфигурация до realfit

`sprint_focal.FocalTeacherBoost()` наследует portable teacher-offset fit/inference
из `LovaszTeacherBoost`, меняя objective/configuration:

- LightGBM200rounds, learning_rate.05, num_leaves63, min_child_samples30,
  reg_lambda5, random_state42, threads2, deterministicTrue/force_col_wiseTrue,
  boost_from_averageFalse, metricNone; все200rounds, no earlystop/validation.
- Preprocessing train-only: median numeric, log1p для неотрицательных столбцов,
  standardization/clip8, unknown-safe categorical OHE; ни одной удалённой строки.
- Loss невзвешенный `L=mean[-(1-p_y)^2 log(p_y)]`, никакой synthetic X/labels.
- Из chain rule для отдельной строки:
  `dL/dz = (1-p_y)*[(1-p_y)-2*p_y*log(p_y)]*(p-onehot_y)/N`.
  Градиент включает derivative фокусирующего множителя; это не detached weight.
  В LightGBM возвращается `N*dL/dz`.
- Численная устойчивость: logsoftmax через logsumexp, `1-p_y` через expm1;
  функция аналитических проверок допускает gamma0 как точный CE, но scientific
  classifier всегда использует gamma2.
- Curvature **суррогатная**: `max(p_k*(1-p_k), .001)`, положительная диагональ CE.
  Она не является точным focal Hessian, не доказана его верхней границей;
  метод использует exact gradient и приближённый положительный preconditioner.
  Guaranteed descent и convexity in logits не заявляются.
- Teacher probabilities только supplied, class columns строго sorted training
  classes; init_score `log(clip(normalized p,1e-12,1))`. Inference складывает
  query teacher logits и raw tree scores ровно один раз, затем softmax.
- Budget до900сек суммарно/hypothesis контролирует runner; inherited callback
  прерывает oversized fit, partial model не засчитывается. Никаких old controlfit.
