## Формула до первого fit, 2026-10-24
Ключ как H70. Для каждого training profile/year средний y; d — разности соседних по времени средних. noise=mean(min(d²,quantile_train(d²,.95)))/2. between=population variance средних y по training profile. В query берётся mean y последнего строго прошлого года; ambiguity=variance y среди строк этого года; alpha=min(.95,max(0,between/(between+noise+ambiguity+1e-12)))*exp(-.25*max(0,queryYear-lastYear-1)). При отсутствии временных пар noise=inf и alpha=0. Prediction=alpha*lastMean+(1-alpha)*тот же кэшированный H43. Все формулы заранее фиксированы, не выбираются по valid.
