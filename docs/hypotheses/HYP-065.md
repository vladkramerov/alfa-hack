# HYP-065 — Инвариантность транспорта схемы и единиц

Дата: 2026-10-24, Москва. Статус до проверки: **Запланирована**. Основание: отдельное поручение на метаморфический аудит без обучения. [Исходная идея](HYP-049-068-proposals.md#hyp-065--инвариантность-к-транспорту-схемы-и-единиц).

Утверждение: обратимые изменения схемы и представления сохраняют смысл готовых предсказаний при `load_task` → `make_submission` → `atomic_submission`. Критерий успеха — все восемь заранее заданных сценариев проходят; числовой допуск 1e-12, строковые метки и ID сравниваются точно. Это проверка семантики, не качества обученной модели или независимой метрики.

До первого запуска зафиксированы ровно восемь сценариев:

1. S01: перестановка строк train и порядка признаков; сравнение X/y по исходным ID и именам.
2. S02: обратимая перестановка test и sample; готовые predictions переставляются тем же отображением; обратное выравнивание по ID.
3. S03: согласованное переименование target/id/признака, включая dictionary; обратное переименование submission.
4. S04: bijection обычных строковых меток классов и предсказаний с точным обратным преобразованием.
5. S05: та же bijection в числоподобные строки `001`/`010`; должны сохраняться лексические метки, включая нули.
6. S06: классы probability-модели и столбцы sample имеют разный порядок; явное отображение в sample order должно сохранять вероятности каждого именованного класса.
7. S07: непрозрачные ID `0007`/`0012` объявлены строковыми; исходное точное ID alignment должно сохраняться при записи и чтении CSV.
8. S08: готовые regression predictions умножаются на 1024, записываются в согласованных единицах и возвращаются делением; исходные значения сохраняются.

Данные только синтетические, fixtures сохраняются в отдельном run. Model fits=0; HTTP/API=0; public score не вычисляется. При ошибке сохраняются evidence, traceback и RED unit, frozen источники SPEC009 не меняются. Сопоставление с платформенным 1376.762 не выполняется.
