# HYP-084: сглаженный posterior сетевых сигнатур с backoff

2026-10-24, [SPEC011](../specs/SPEC-011-three-hour-improvement.md). Статус: зафиксирована до научного fit, не оценивалась. Прямое поручение координатора реализовать указанную фиксированную формулу; новый learner не запускать в рамках реализации.

## Механизм и новизна

Прямой классификатор условных частот классов по иерархии дискретных сетевых сигнатур, со сглаживанием к train prior и ограниченным арифметическим смешиванием с готовым teacher. H16 добавляла только категориальное взаимодействие в LightGBM; H17 добавляла частоты X без y; H52 использовала 25NN по смешанному расстоянию всех признаков; H40 обучала парных специалистов. Здесь меняются estimator и явное правило backoff/shrinkage, а не seed, имя или только границы бинов старой модели. Это разновидность локальной памяти, без заявления о независимости свидетельств или точном байесовском posterior.

## Зафиксированная конфигурация

- Категориальный ключ: точный tuple(`proto`, `service`, `state`). Значения и пропуски кодируются разными tagged tokens; неизвестное значение не совпадает с пропуском.
- Четыре кумулятивных уровня: категории; +(`sttl`, `dttl`); +(`spkts`, `dpkts`); +(`sbytes`, `dbytes`). TTL преобразуется в `floor(value/32)`, пакеты и байты — `floor(log2(1+value))`. Пропуск/нечисловое/бесконечное числовое значение имеет отдельный token, отличный от нуля; отрицательное — отдельный invalid token. Никаких статистик для границ бинов из validation/test.
- Выбирается наиболее подробный уровень с числом train-строк `n>=8`. Если такого уровня нет, возвращается teacher без изменения.
- Классы — лексически отсортированные строковые train labels, без утраты ведущих нулей. `pi_k=N_k/N`, без class weights и выравнивания prior.
- `q_k=(count_k+20*pi_k)/(n+20)`; `alpha=.5*n/(n+50)`; `p_k=(1-alpha)*teacher_k+alpha*q_k`. Итоговый класс — первый максимум в отсортированном порядке. Никакого произведения posterior, деления на class prior, калибровки или выбора коэффициентов по training/validation F1.
- Fit строит таблицы только из X/y train. Переданный training teacher проверяется по размерности, порядку именованных колонок и корректности вероятностей, но не влияет на таблицы, prior или коэффициенты. На query необходим teacher той же размерности; статистики всего query batch не используются.
- ID/target/прочие столбцы не входят в ключи. Строки не удаляются, новые признаки-индикаторы не добавляются. Неизвестные подписи используют указанный backoff; внешний label lookup отсутствует.

## Протокол, критерий и ограничения

Исходные multiclass CSV/SHA и grouped splits SPEC011, teacher только из готовых совместимых артефактов; training teacher может быть in-sample, что не является независимой оценкой. Таблицы строятся заново только на разрешённом fit. Любая последующая калибровка/подбор смеси по обучающим table predictions потребовала бы отдельного grouped cross-fitting и здесь отсутствует. Сглаживание точных дубликатов само по себе при сохранении массы алгебраически не меняет CE; научная гипотеза здесь — другой прямой estimator на укрупнённых сигнатурах.

Сначала фиксированный inner raw-fold0 proxy; сравнивать с его cached teacher и уже полученными новыми inner результатами, включая H78, без их refit. На исходный outer переносить только заранее выбранного финалиста. Контроль H48 Macro-F1 `.6495311620074445`, цель20% `>=.7794373944089334`; просмотренный outer остаётся разведочным, платформа неизвестна. До900сек на гипотезу, память и inference фиксированных таблиц ограничены числом train-строк. Сильный empirical prior может подавлять редкие классы; формула не обещает выигрыша.
