# HYP-009: LightGBM с нативными категориями

Дата: 2026-10-23. Статус: Выполнена. [SPEC-003](../specs/SPEC-003-platform-agent.md).
История 33 старых оценок, 16 trials и 65 новых оценок изучена: семейство LightGBM в них не проверялось.
Гипотеза: leaf-wise LightGBM с нативными категориями улучшит сохранённую контрольную метрику без агрессивного pruning/Gaussian preprocessing.
Фиксировано до запуска: 500 trees, learning_rate0.05, num_leaves31, min_child_samples20, reg_lambda1, random_state42, n_jobs4; numeric median, train-only категории.
Обе задачи: исходный временной outer regression years1-4→5 и grouped outer classification из SPEC-002; никаких повторных baseline fit.
Критерий: меньший RMSE / больший Macro F1 относительно совместимых сохранённых оценок; сравнение с известным историческим regression43.004639 отмечается как внешний ориентир.
Каждый запуск сохранён отдельно. Исходная формулировка до запуска: Не оценивалась.

Результаты: [regression](../../results/2026-10-23/HYP-009-01-regression-lightgbm/report.md) RMSE60.492688256314 — не подтверждена; [multiclass](../../results/2026-10-23/HYP-009-02-multiclass-lightgbm/report.md) Macro F1 0.583855959368 — подтверждена в проверенных условиях против RF0.577365823912. Повторно использован validation: независимого подтверждения нет.
