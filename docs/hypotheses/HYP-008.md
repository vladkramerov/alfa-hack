# HYP-008: самостоятельный feature engineering без удаления новых полей

- Дата: 2026-10-23, Москва.
- Статус: Проверена.
- Спецификация: [SPEC-002](../specs/SPEC-002-preprocessing-model-comparison.md).

## Причина дополнительной проверки

В основной cumulative серии все шесть добавленных network features были удалены correlation/VIF selection; gaussian и engineered CatBoost дали одинаковые признаки и метрику.
Это не проверяет полезность сохранённых новых признаков. Поэтому отдельно сравниваем engineering-only с исходным baseline для обоих семейств и обоих датасетов.
Решение о дополнительном контроле принято после просмотра основной inner-диагностики и части regression outer; это разведочный анализ на повторно используемых splits, не новый независимый тест.

## Утверждение и критерий до запуска

Feature engineering из исходных единиц с сохранением всех новых признаков улучшает RMSE / Macro F1 относительно baseline imputation+onehot.
Единственное семейство изменений — `engineer=True`; correlation/VIF/scaling/Yeo–Johnson выключены.
Параметры CatBoost и Random Forest, seed и все splits полностью совпадают с основной серией.
До первого fit фиксируется панель обеих моделей и двух stages; по этой дополнительной серии основной frozen winner не меняется.
Критерий: RMSE ниже соответствующего baseline или Macro F1 выше него, на идентичных validation-объектах.
