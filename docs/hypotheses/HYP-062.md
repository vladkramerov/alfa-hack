# HYP-062: низкоранговые взаимодействия в исходной шкале

Дата регистрации протокола:2026-10-24; до реального fit. [SPEC010](../specs/SPEC-010-clean-rewrite.md); первоначальная идея — [H49–68](HYP-049-068-proposals.md). Статус: запланирована, не проверена.

Утверждение: совместно обученные попарные взаимодействия FM могут уменьшить regression RMSE относительно H69. Это не spline GAM, log-residual correction, новая комбинация прежних экспертов или ещё один seed. Недооценка хвоста прежним лидером мотивирует squared loss в исходных единицах, но не доказывает роль именно взаимодействий.

Конфигурация: research_fm.FactorizationRegressor(rank8,epochs20,batch512,lr.005,L2.001,seed42); Adam beta .9/.999 eps1e-8, init factorsN(0,.01). Fit-only numeric median/standardization/missingflags + lexical OHE(unknownignore), без удаления строк. y affine train mean/std лишь для устойчивости оптимизации, predict обратно в исходные единицы; не log target. L2 действует в стандартизованной шкале таргета. CSR без sample×sample allocation.

Данные: исходный data/regression, target site_eui; ID исключён. Confirmation train Year_Factor<4 →4; inner внутри confirmation-fit (годы<3→3). Год5 не используется для новых решений. До900сек на стадии гипотезы суммарно, <=4threads. Source/data/splits/params до fit фиксируются frozen-plan.json.

Критерий: RMSE в исходной шкале против заново обученного H69 на том же дополнительном confirmation. Один новый кандидат, без подбора параметров по confirmation. Итоговая поставка только по REQ1009 и preflight. Ошибка/timeout не опровергает гипотезу.

До допуска к данным пройдены finite differences и независимый попарный oracle, train-only/unknown/missing/constanty и held-out synthetic interaction test. Каждая стадия сохраняется отдельно results/HYP-062-NN-* и сразу дописывается в единый журнал.
