# HYP-052: смешанное локальное расстояние

Дата регистрации протокола:2026-10-24; до реального fit. [SPEC010](../specs/SPEC-010-clean-rewrite.md); первоначальная идея — [H49–68](HYP-049-068-proposals.md). Статус: запланирована, не проверена.

Утверждение: фиксированный 25NN по capped numeric L1/fit-IQR и категориальным несовпадениям может отделять локально смешанные классы лучше текущего H48. Геометрия — новый механизм, не параметры дерева/SMOTE/частот/калибровки. Срезы прежнего holdout лишь мотивируют вопрос, не определяют веса/пороги.

Точная конфигурация: research_neighbors.MixedNeighborsClassifier(n_neighbors=25), train-only median/IQR, cap3, numeric missing flags, равный вклад доступных типов; равное голосование и детерминированные ничьи. query128/train8192 blocks ограничивают RAM без изменения расстояния. Fit-only словари, неизвестная категория не совпадает с известной/пропуском.

Данные: исходный data/multiclass, target attack_cat, ID исключён; hashes и позиции до fit фиксирует series-clean-rewrite-v1/frozen-plan.json. Confirmation — SGKF5(seed42), fold1 по исходным лексическим raw-X группам; inner внутри confirmation-fit, без пересечения групп. Старый outer не повторяется. До900сек суммарно на стадии гипотезы, включая inner/confirmation/разрешённый контроль; <=4threads.

Критерий: честное сравнение Macro-F1 с заново обученным H48 на том же дополнительном confirmation; без frozen public meta-state. Один фиксированный новый кандидат, никаких параметров по confirmation. Итоговая поставка проходит согласованное двухзадачное правило REQ1009. Ошибка/timeout — недостаточно данных, не отрицательная ML-метрика.

Артефакты каждой стадии: отдельные results/HYP-052-NN-*, evidence/source/split/metrics/predictions/report/log. Производные/алгебра: exact brute-force synthetic tests пройдены до реальных данных. Нахождение близких точек не доказывает шум разметки.
