# Локальная приёмка перед отправкой на платформу

Статус: локальные проверки SPEC-003 выполнены; ZIP 15 230 байт. Реальный API платформы НЕ проверен (env отсутствуют), установка полного предоставленного requirements с нуля не выполнялась; проверены используемые версии Python3.12/numpy/pandas/scipy/sklearn/CatBoost/LightGBM.
Основание: [уточнение организаторов](sources/platform-update-2026-10-23.md), [SPEC-001](specs/SPEC-001-automl-agent.md).
Локальные ML-experiments в experiments/ являются отдельными инструментами и не соответствуют формату root-only ZIP автоматически.

## Обязательные проверки будущего пакета

- [x] ZIP не более 100 МБ; до уточнения единиц использовать консервативный предел 100 000 000 байт.
- [x] solution.py и исходный requirements.txt лежат в корне; все необходимые Python-модули также в корне.
- [x] В чистую временную папку скопированы ТОЛЬКО root .py и requirements.txt; агент запускается из неё без исходного checkout.
- [x] Нужные модули доступны без вложенных Python-папок, data/ и служебных файлов рабочего проекта.
- [x] Предоставленный requirements.txt не подменён requirements-experiments.txt; нет установки пакетов в runtime.
- [x] Основной процесс, дочерний Python и воркеры импортируют необходимые модули в целевом окружении Python 3.12.
- [x] Проверены несколько локальных условий с разными путями, именами target/id и типами задачи.
- [x] Пути CSV взяты из task.md и разрешаются относительно его каталога, независимо от cwd; проверено расположение всех четырёх CSV.
- [x] OPENAI_BASE_URL и OPENAI_API_KEY берутся из окружения платформы; endpoint соответствует инструкции, секреты не логируются.
- [x] Локальные сценарии моделируют timeout, API error, пустой choices, пустой content, обрезанный JSON и ошибочные tool arguments.
- [x] Ошибка LLM не уничтожает уже готовый результат; повторные запросы и бюджет ограничены.
- [x] Известные гипотезы/конфигурации не запускаются заново; используются журнал и fingerprint данных/split/preprocessing/params.
- [x] Есть резерв времени на обучение/предсказание/сохранение до трёхчасового лимита; корректный fallback доступен заранее.
- [x] submission.csv существует рядом с task.md, не пуст, имеет ожидаемые число строк и столбцы, правильные id/порядок/значения.
- [x] Проверен перенос результата из временной папки, если она использовалась.
- [x] Полный локальный smoke пройден до загрузки; отчёт сохранён в results/ с фактическими проверками и ограничениями.

Запись критерия не означает успешную проверку; отметки ставятся только после выполнения.
Подробные платформенные логи не предполагаются; самостоятельная диагностика сохраняется локально.
Учитываются максимум 3 сабмита/день по PDF и максимум 2 запроса логов/день по уточнению; автоматическая отправка этим документом не разрешается.
