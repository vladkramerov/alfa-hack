# Документация проекта

Получены условия хакатона, baseline, список зависимостей и два публичных датасета.
Требования по материалам собраны в [SPEC-001](specs/SPEC-001-automl-agent.md); это черновик, не согласованный дизайн реализации.
Состав материалов, проверенные характеристики и несоответствия описаны в [обзоре источников](sources/README.md).
Основной процесс описан в [Codex.md](../Codex.md).
Единая память проверок — [HYPOTHESES.md](../HYPOTHESES.md), обязательное чтение перед каждой гипотезой. [SPEC-003](specs/SPEC-003-platform-agent.md) и [новые результаты](../results/2026-10-23/NEW_EXPERIMENT_REPORT.md) описывают локально проверенный агент; реальный API пока не проверен.

| Папка | Содержимое |
| --- | --- |

## Когда появится первая задача

1. Скопируй `specs/_template.md` в `specs/SPEC-001-<slug>.md` и заполни требования.
2. После согласования требований создай `plans/PLAN-001-<slug>.md` из шаблона, свяжи его со спецификацией.
3. Если нужно проверить предположение, создай `hypotheses/HYP-001-<slug>.md` и заранее задай критерий успеха.
4. Выполни работу и проверки; каждый запуск гипотезы сохрани в отдельную папку `results/`, обнови журнал.

Используй последовательные уникальные идентификаторы внутри каждого типа документов и относительные ссылки между ними.
Файлы `_template.md` — заготовки, а не действующие требования или проведённые эксперименты.
